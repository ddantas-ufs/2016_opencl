# 2016_opencl

Benchmark comparison of VisionGL, Python and MATLAB. Code used in conference paper published in ICIP 2016 [1].

Requires library [VisionGL release v0.1 from GitHub](https://github.com/ddantas/visiongl/releases/tag/v0.1).

Fast multidimensional image processing with OpenCL \
